# Changelog

All notable changes are documented here.

## 0.1.0 - 2026-09-03

### Added

- Compatibility planning for selected PostgreSQL schemas and tables.
- Read-only, locked, repeatable-read export using PostgreSQL COPY text format.
- SQLite/D1 schema generation for ordinary tables, keys, foreign keys, enums, and btree column indexes.
- Size-bounded batched inserts and multi-file bundles.
- Local, preview, and explicitly confirmed remote Wrangler application modes.
- SHA-256 bundle integrity checks, row-count verification, and foreign-key verification.
- English and Japanese documentation, synthetic test fixtures, CI, and public-safety scanning.
- Windows- and Unicode-safe source validation paths.
